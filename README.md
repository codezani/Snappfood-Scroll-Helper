# Snappfood Scroll Helper

افزونه فایرفاکس برای اسکرول راحت‌تر در سایت **اسنپ‌فود** با کلیدهای `Page Up` و `Page Down`.

## ویژگی‌ها

- اسکرول به بالا و پایین با کلیدهای `Page Up` و `Page Down`
- نمایش نشانگر جهت (بالا / پایین) در بالای صفحه
- سازگار با ساختار React اسنپ‌فود
- فقط روی دامنه‌های `snappfood.ir` کار می‌کند
- سبک و بدون نیاز به دسترسی‌های اضافی

## کلیدها

| کلید          | عملکرد             |
|---------------|--------------------|
| **Page Down** | اسکرول به پایین    |
| **Page Up**   | اسکرول به بالا     |

## نصب

### روش موقت (برای تست)

1. فایرفاکس را باز کنید.
2. به آدرس زیر بروید:

   about:debugging#/runtime/this-firefox

3. روی **Load Temporary Add-on…** کلیک کنید.
4. فایل `manifest.json` را انتخاب کنید.

### روش دائمی

فعلاً این افزونه به صورت موقت قابل نصب است. برای نصب دائمی باید در [addons.mozilla.org](https://addons.mozilla.org) منتشر شود.
